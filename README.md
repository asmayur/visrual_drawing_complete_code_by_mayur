# Virtual Air Paint

A browser-based AI-powered hand-tracking drawing application that allows users to paint in the air using real-time gesture recognition with MediaPipe Hands and HTML5 Canvas.

## Features

* Real-time finger-based AIR drawing
* Smooth hand gesture tracking
* AI-powered cursor movement
* Multiple color selections
* Adjustable brush size
* Eraser support
* Undo / Redo functionality
* Clear canvas option
* Webcam-based hand tracking
* Optimized rendering and motion smoothing

## Technologies Used

* HTML5 Canvas
* JavaScript
* MediaPipe Hands
* Computer Vision
* Real-time Gesture Tracking
* requestAnimationFrame Rendering

## How to Run

1. Open the project folder in your terminal.
2. Start a local server:

   ```bash
   python -m http.server 8000
   ```
3. Open the application in your browser:

   ```text
   http://127.0.0.1:8000/index.html
   ```

## Requirements

* Modern browser with webcam support
* Webcam permission enabled
* Python (for local server) or any static file server

## Notes

* Allow camera access when prompted by the browser.
* Best experience recommended on desktop/laptop webcam.
* Optimized for smooth real-time hand tracking and AIR drawing.
